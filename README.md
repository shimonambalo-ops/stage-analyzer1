# מסלול: אבחון שלב חברה

אתר שמקבל טיקר ומאבחן באיזה שלב באבולוציה החברה נמצאת: סטארטאפ, צמיחה, מעבר לרווח נקי או ערך.
האבחון מבוסס על המסגרת מהסרטון של דביר שלום. האתר מציג גם את רמת הסיכון ביחס לשלב, ומתריע כשחברה **על סף מעבר** לשלב הבא.

## מה יש באתר
- **סקירה:** השלב על מסלול האבולוציה, התראות "על הסף", תמונת מצב במילים, סימני אזהרה ונקודות חוזק, מד סיכון,
  ציונים 1–10 וכמה זמן הקופה מחזיקה.
- **גרף:** המחיר על רקע השלב שאובחן בכל רבעון, עם סימון המעבר לרווח נקי ותשואות לתקופות שונות.
- **נתונים מרכזיים:** מכפילים, רווחיות, חוסן, מסחר ובעלות, ויעדי אנליסטים.
- **דוחות כספיים:** טבלה של 5 שנים וגרפים רבעוניים: הכנסות, רווח, תזרים, מזומן מול חוב ומספר מניות.
- **עדכונים אחרונים:** כותרות מתורגמות לעברית, כתבות מהתקשורת בישראל, ודיווחים רשמיים ל-SEC עם הסבר בעברית,
  כולל התראה על תשקיפי מדף (אפשרות לדילול) ועסקאות של בעלי עניין.
- **על החברה:** מה החברה עושה, פרטים כלליים, ומה קרה למניה אחרי שעברה לרווח נקי.

## העלאה ל-Vercel (חינם)
1. נכנסים ל-vercel.com, לוחצים **Sign Up** ומתחברים עם GitHub.
2. לוחצים **Add New…** ← **Project** ← בוחרים את המאגר `stage-analyzer1` ← **Import**.
3. ב-**Framework Preset** משאירים **Other**. לא משנים שום דבר בהגדרות הבנייה.
4. פותחים את **Environment Variables** ומוסיפים:
   - Name: `SEC_USER_AGENT`
   - Value: השם והמייל שלך, למשל `Shimon Ambalo your@email.com`
5. לוחצים **Deploy**. אחרי דקה–שתיים מתקבלת כתובת בסגנון `stage-analyzer1.vercel.app`.

כל שינוי שנשמר במאגר ב-GitHub עולה לאתר אוטומטית.

## מבנה
| קובץ | תפקיד |
|---|---|
| `public/` | האתר עצמו: `index.html`, `styles.css`, `app.js`, ו-ECharts לגרפים |
| `api/analyze.py` | אבחון: דוחות SEC, מחירים, שלב, סיכון, "על הסף" |
| `api/extras.py` | פרופיל, מועד הדוח הבא, נתוני מסחר, אנליסטים, חדשות ודיווחים ל-SEC |
| `api/tickers.py` | רשימת הטיקרים להשלמה אוטומטית בחיפוש |
| `webapi.py` | הלוגיקה של ה-API |
| `analysis.py` | מנוע האבחון, הסיכון, הציונים וזיהוי "על הסף" |
| `sec_data.py` | משיכת הדוחות מ-SEC ופירוקם לסדרות רבעוניות |
| `profile_data.py`, `news_data.py` | פרופיל, תרגום, חדשות ודיווחים |
| `legacy/` | גרסת ה-Streamlit הקודמת (לא בשימוש) |

## מקורות נתונים (כולם בלי מפתח API)
- **SEC EDGAR:** דוחות כספיים רשמיים והיסטוריית דיווחים.
- **Yahoo Finance (yfinance):** מחירים, פרופיל, נתוני מסחר, אנליסטים וכותרות.
- **Google News RSS:** כותרות, כולל בעברית.
- **Google Translate (deep-translator):** תרגום התיאור והכותרות.

## מגבלות
- נתמכות רק חברות שמגישות דוחות ל-SEC. מניות שנסחרות רק בתל אביב לא נתמכות.
- חברות זרות שמגישות רק דוח שנתי מאובחנות לפי נתונים שנתיים.
- הספים נקבעו לפי ההיגיון בסרטון. הנוסחאות המדויקות של דביר נלמדות בקורס.
- כלי לימודי, לא ייעוץ השקעות.
