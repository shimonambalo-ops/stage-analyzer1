# אבחון שלב חברה – סטארטאפ ← צמיחה ← ערך

כלי שמקבל טיקר ומאבחן באיזה שלב באבולוציה החברה נמצאת (לפי המסגרת מהסרטון של דביר שלום),
ומה רמת הסיכון שלה ביחס לשלב. הנתונים אמיתיים: דוחות רשמיים מ-SEC EDGAR ומחירים מ-Yahoo Finance.
אין צורך במפתח API.

## הרצה (Windows)

**הכי פשוט:** לחיצה כפולה על `run.bat`. הוא מתקין את הספריות ופותח את הכלי בדפדפן.

אם החלון נסגר מיד (Python לא מוגדר ב-PATH), פתח **Anaconda Prompt**, ועבור לתיקייה:

```
cd C:\Users\<שם המשתמש>\Documents\stage_analyzer
pip install -r requirements.txt
streamlit run app.py
```

### הגדרה חד-פעמית (מומלץ)
SEC מבקשת שכל בקשה תזדהה בשם ומייל. העתק את `.streamlit/secrets.toml.example` ל-`.streamlit/secrets.toml`
ושים שם את הפרטים שלך. אפשר גם פשוט להקליד אותם בסרגל הצד בכל הרצה.

## מה הכלי עושה

| שלב | איך מאובחן (ברירת מחדל, ניתן לשינוי בסרגל הצד) |
|---|---|
| סטארטאפ | הכנסות 12 חודשים מתחת ל-$25M |
| מעבר סטארטאפ ← צמיחה | חצתה את סף הסטארטאפ בשנתיים האחרונות, או הכפילה הכנסות בהיקף של עד $1B |
| צמיחה הפסדית | צמיחה של 20%+ בשנה, הפסד נקי |
| **מעבר לרווח נקי (Money Time)** | רווח 12 החודשים הפך לחיובי לראשונה ב-4 הרבעונים האחרונים |
| צמיחה רווחית | צמיחה של 20%+, רווחית |
| מעבר צמיחה ← ערך | רווחית, צמיחה של 8%–20% |
| ערך | רווחית, צמיחה מתחת ל-8% |
| מעבר ערך ← צמיחה | הייתה בצמיחה נמוכה וחזרה להאיץ מעל 20% |
| הפסדית בצמיחה איטית / התכווצות | מחוץ למסלול הבריא – סימן אזהרה |

**מדדי בריאות:**
- כמה זמן הקופה מחזיקה: בשתי שיטות. תזרים חופשי (מדויק), והפסד נקי (השיטה מהסרטון).
- הערכה מתי תגיע לרווח נקי לפי מגמת ההפסדים, והאם הקופה מספיקה עד אז.
- מזומן מול חוב, דילול שנתי, תגמול במניות ביחס להכנסות.
- מכפילים (P/S, P/E) ותנודתיות.

**סיכון (0–100):** בסיס לפי השלב, ועליו תוספות והפחתות לפי הקופה, החוב, הדילול, מגמת ההפסדים,
האטה בצמיחה, תמחור ותנודתיות. כל רכיב מוצג עם הסבר.

**פרופיל החברה:** מה החברה עושה (מתורגם לעברית), סקטור, מטה, עובדים, אתר, הדוח האחרון
ומתי צפוי הדוח הבא – לפי Yahoo Finance, ואם אין – הערכה לפי קצב הדיווחים ב-SEC.
"תמונת מצב" – סיכום במילים של מצב החברה, וציונים 1–10 לצמיחה, רווחיות, חוסן פיננסי ותמחור.

**אירועי מעבר לרווח:** הכלי מזהה מתי החברה עברה לרווח נקי, ומחשב את התשואה מיום פרסום הדוח,
כמו הדוגמאות של Palantir, SoFi ו-Robinhood בסרטון.

## מגבלות
- נתמכות רק חברות שמגישות דוחות ל-SEC. מניות שנסחרות רק בתל אביב לא נתמכות.
- חברות זרות שמגישות 20-F (שנתי בלבד) מאובחנות לפי נתונים שנתיים, ולכן פחות מדויק.
- נתוני XBRL לפעמים חסרים או מתויגים אחרת. בעיקר החוב הוא קירוב. בלשונית "נתונים גולמיים"
  רואים בדיוק מאיזה שדה נלקח כל נתון.
- הספים נקבעו לפי ההיגיון בסרטון. הנוסחאות המדויקות של דביר נלמדות בקורס שלו.
- כלי לימודי, לא ייעוץ השקעות.

## קבצים
- `app.py` – הממשק (Streamlit)
- `profile_data.py` – פרופיל החברה, מועד הדוח הבא ותרגום התיאור
- `sec_data.py` – משיכת נתונים ופירוק הדוחות (כולל השלמת רבעון 4 וחישוב רבעוני מתזרים מצטבר)
- `analysis.py` – מנוע האבחון והסיכון
- `tests/` – בדיקות לוגיקה (`python tests/test_engine.py`)
