# מסלול: אבחון שלב חברה

אתר שמקבל טיקר ומאבחן באיזה שלב במחזור החיים החברה נמצאת, ומה רמת הסיכון שלה ביחס לשלב.
האבחון מבוסס על שני מודלים מוכרים, והרעיון לקוח מהסרטון של דביר שלום על האבולוציה של חברה.

## המודל
**Dickinson (2011): מנוע האבחון.** Dickinson, V. "Cash Flow Patterns as a Proxy for Firm Life Cycle", The Accounting Review 86(6).
השלב נקבע לפי הסימן (+ או −) של שלושת חלקי דוח תזרים המזומנים ב-12 החודשים האחרונים: פעילות שוטפת, השקעות ומימון.
יש 8 צירופים אפשריים, והם מתחלקים ל-5 שלבים, בלי ספים:

| פעילות שוטפת | השקעות | מימון | שלב |
|---|---|---|---|
| − | − | + | היכרות |
| + | − | + | צמיחה |
| + | − | − | בשלות |
| − − −, + + +, + + − | | | התנערות |
| − + +, − + − | | | דעיכה |

התאמה שלנו: מתזרים ההשקעות מנוטרלות קנייה ומכירה של ניירות ערך סחירים, לפי השינוי ביתרתם במאזן. זה ניהול של הקופה ולא השקעה בעסק.

**Damodaran: עדשה שנייה.** מחזור החיים של Aswath Damodaran כולל שישה שלבים לפי צמיחה ורווחיות: סטארטאפ, צמיחה צעירה, צמיחה גבוהה,
צמיחה בשלה, בשלות יציבה ודעיכה. לכל שלב יש גישת תמחור משלו. Damodaran מתאר את השלבים במילים, והספים המספריים הם התרגום שלנו:
הכנסות זניחות מתחת ל-25 מיליון דולר, צמיחה גבוהה מ-20%, בשלה בין 8% ל-20%, יציבה מתחת ל-8%.

**שכבה מהסרטון:** "מעבר לרווח נקי". המערכת מזהה את הרבעון שבו הרווח הנקי השנתי הפך לחיובי, לא כולל רווח שמקורו בסעיפים לא תפעוליים,
ומחשבת מה קרה למניה מאז.

**"על הסף":** אחד משלושת התזרימים קרוב לאפס, ומגמת 4 הרבעונים האחרונים צפויה להפוך את הסימן שלו. במצב כזה השלב צפוי להשתנות.

## העלאה ל-Vercel (חינם)
1. נכנסים ל-vercel.com, לוחצים **Sign Up** ומתחברים עם GitHub.
2. לוחצים **Add New…** ← **Project** ← בוחרים את המאגר `stage-analyzer1` ← **Import**.
3. ב-**Framework Preset** בוחרים **Python** (בדרך כלל Vercel מזהה את זה לבד). לא משנים שום דבר בהגדרות הבנייה.
4. פותחים את **Environment Variables** ומוסיפים:
   - Name: `SEC_USER_AGENT`
   - Value: השם והמייל שלך, למשל `Shimon Ambalo your@email.com`
5. לוחצים **Deploy**. אחרי דקה–שתיים מתקבלת כתובת בסגנון `stage-analyzer1.vercel.app`.

כל שינוי שנשמר במאגר ב-GitHub עולה לאתר אוטומטית.

## מבנה
| קובץ | תפקיד |
|---|---|
| `public/` | האתר עצמו: `index.html`, `styles.css`, `app.js`, ו-ECharts לגרפים |
| `app.py` | נקודת הכניסה: מגיש את האתר ואת ה-API (`/api/analyze`, `/api/extras`, `/api/tickers`). הרצה מקומית: `python app.py` |
| `webapi.py` | הלוגיקה של ה-API |
| `analysis.py` | מנוע האבחון, הסיכון, הציונים וזיהוי "על הסף" |
| `sec_data.py` | משיכת הדוחות מ-SEC ופירוקם לסדרות רבעוניות |
| `profile_data.py`, `news_data.py` | פרופיל, תרגום, חדשות ודיווחים |
| `verify.py` | בדיקות אמינות ומקור (דוח + שדה) לכל נתון |
| `legacy/` | גרסת ה-Streamlit הקודמת (לא בשימוש) |

## מקורות נתונים (כולם בלי מפתח API)
- **SEC EDGAR:** דוחות כספיים רשמיים והיסטוריית דיווחים.
- **Yahoo Finance (yfinance):** מחירים, פרופיל, נתוני מסחר, אנליסטים וכותרות.
- **Google News RSS:** כותרות, כולל בעברית.
- **Google Translate (deep-translator):** תרגום התיאור והכותרות.

## מגבלות
- נתמכות רק חברות שמגישות דוחות ל-SEC. מניות שנסחרות רק בתל אביב לא נתמכות.
- חברות זרות שמגישות רק דוח שנתי מאובחנות לפי נתונים שנתיים.
- הספים נקבעו לפי ההיגיון בסרטון. הנוסחאות המדויקות של דביר נלמדות בקורס.
- כלי לימודי, לא ייעוץ השקעות.
